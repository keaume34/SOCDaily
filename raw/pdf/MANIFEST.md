# SOCDaily Source Material Manifest

PDFs are **not committed** (large + likely copyrighted). To run the pipeline,
populate `raw/pdf/` with the files below — each in its mapped subfolder.

The folder structure is the loose categorization Devin used during ingest; the
LLM-generated outline will further organize topics into Subjects/Chapters.

```
raw/pdf/
├── basics/                  # Cybersecurity & SOC fundamentals
├── blue-team/               # Defender-side hands-on material
├── books/                   # Full textbooks
├── interview/               # Q&A banks (great for MCQ seeding)
├── references/              # Links, video lists, datasheets
├── siem/                    # SIEM products + queries
├── soc-general/             # SOC governance, structure, overview
└── topics/                  # Topic-specific notes (phishing, IDS/IPS, XDR, …)
```
